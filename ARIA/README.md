# ARIA — Personal AI Operating Layer

CAI Workshop — Beyond the Classroom, Option 2.

ARIA is a startup concept for a personal AI assistant and companion that understands context, remembers what matters, adapts communication, works across modalities, and acts only with appropriate user permission.

## Website
Static HTML/CSS/JS. Open `index.html` locally or deploy the `ARIA` folder as a static site.

## Assignment deliverables
- Functional startup website
- Startup pitch: `pitch.md`
- Development prompts: `prompts.md`
- GitHub repository with project history

## Core principle
**Understand → Remember → Help → Act → Learn**

**Your context. Your AI. Your control.**

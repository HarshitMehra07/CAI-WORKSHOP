# ARIA — Personal AI Operating Layer

A polished startup website for the CAI Workshop — Beyond the Classroom, **Option 2: Build a Website for a Startup Idea**.

## Startup idea
ARIA is a personal AI assistant and companion designed to understand a user's context, remember important information, adapt communication naturally, work across text/voice/camera/screen/internet/computer interaction, and eventually act with explicit user permission.

## Website
Static HTML/CSS/JS. No build step required.

- `index.html` — complete ARIA landing page
- `styles.css` — responsive visual system and animations
- `script.js` — scroll reveal and interactive orb
- `pitch.md` — startup pitch
- `prompts.md` — development prompts used during creation
- `ARIA_Startup_Pitch.pdf` — themed startup pitch document

## Run locally
Open `index.html` in a browser or serve the folder with any static server.

## Deployment
The repository is intended to be connected to Netlify for continuous deployment. Netlify can deploy directly from a Git repository and redeploy on pushes to the production branch.

## GitHub collaboration
For the assignment, use meaningful commits and, if working in a group, separate branches and pull requests so contributions are visible in GitHub history.
